


# Dự án Website Phòng Khám Nha Khoa

> Dự án phát triển **website quản lý và tổ chức phòng khám nha khoa** hỗ trợ *quản lý, lọc và theo dõi bảng tính phiếu điều trị*

## Cấu trúc thư mục

| Thư mục  | Nội dung |
| :-: | :-- |
| docs | Hướng dẫn chăm sóc  |
| media | logo nha khoa |
| data | Chứa dữ liệu bảng tính Excel |
| logs | Chứa các file hệ thống và báo cáo lỗi |
| backup | logo nha khoa |

## Lệnh liệt kê cấu trúc dự án

```
Get-ChildItem -Recurse -Force
```
## Mục đã hoàn thiện
- [x] Khởi tạo cấu trúc thư mục và tên file theo chuẩn snake_case
- [x] Dòng mô tả có cả in đậm và in nghiêng
- [ ] Hoàn thiện các script tự động lọc log báo cáo
>  *Lưu ý:* **Không** upload file `.env` lên GitHub
